# CLI Reference

TinyFlag includes a CLI for validating flag files, generating TypeScript types, and comparing flag changes.

## Installation

```bash
npm install -g tinyflag-cli
# or use with npx
npx tinyflag <command>
```

## Commands

### `validate`

Validate a flag file against the schema.

```bash
npx tinyflag validate ./flags.yml
```

Exit code `0` on success, `1` on failure with detailed error messages:

```
❌ flags.yml validation failed:
  - flags.new-checkout.rollout: must be 0-100, got 150
  - flags.dark-mode: missing required field "enabled"
```

### `generate`

Generate TypeScript type definitions from a flag file.

```bash
npx tinyflag generate ./flags.yml                    # stdout
npx tinyflag generate ./flags.yml -o ./src/flags.d.ts # write to file
```

Output:

```typescript
// Auto-generated by tinyflag — do not edit
export interface TinyFlagDefinitions {
  'new-checkout': { variants: 'control' | 'new-flow' };
  'dark-mode': { variants: never };
}
```

### `diff`

Show flag changes between two git refs.

```bash
npx tinyflag diff main..HEAD
npx tinyflag diff main..HEAD --file config/flags.yml
```

Output:

```
🚩 Flag changes (main → HEAD):
  + payment-v2 (enabled: true, rollout: 10%)
  ~ new-checkout:
      rollout: 10% → 50%
  - legacy-nav (removed)
```
