# CLI Reference

## Installation

```bash
npm install -g tinyflag-cli
# or use with npx
npx tinyflag <command>
```

## Global Options

| Option   | Description                                           |
| -------- | ----------------------------------------------------- |
| `--json` | Output structured JSON instead of human-readable text |

## `validate`

Validate a flag file against the schema.

```bash
npx tinyflag validate <file> [options]
```

| Option     | Description                                     |
| ---------- | ----------------------------------------------- |
| `--strict` | Reject unknown fields as errors                 |
| `--watch`  | Re-validate automatically when the file changes |
| `--json`   | Output structured JSON                          |

**Exit codes:** `0` on success, `1` on failure.

### Examples

```bash
npx tinyflag validate ./flags.yml
npx tinyflag validate ./flags.yml --strict
npx tinyflag validate ./flags.yml --watch --strict
```

### JSON Output

```json
{
  "command": "validate",
  "file": "./flags.yml",
  "valid": true,
  "flagCount": 3,
  "flags": ["dark-mode", "new-checkout", "payment-v2"]
}
```

## `generate`

Generate TypeScript type definitions from a flag file.

```bash
npx tinyflag generate <file> [options]
```

| Option   | Description                        |
| -------- | ---------------------------------- |
| `-o`     | Output file path (default: stdout) |
| `--json` | Output structured JSON             |

### Examples

```bash
npx tinyflag generate ./flags.yml
npx tinyflag generate ./flags.yml -o ./src/flags.d.ts
```

### Generated Output

```typescript
// Auto-generated by tinyflag — do not edit
export interface TinyFlagDefinitions {
  'new-checkout': { variants: 'control' | 'new-flow' };
  'dark-mode': { variants: never };
}
```

## `diff`

Show flag changes between two git refs.

```bash
npx tinyflag diff <ref1>..<ref2> [options]
```

| Option   | Description                               |
| -------- | ----------------------------------------- |
| `--file` | Path to flags file (default: `flags.yml`) |
| `--json` | Output structured JSON                    |

### Examples

```bash
npx tinyflag diff main..HEAD
npx tinyflag diff main..HEAD --file config/flags.yml
npx tinyflag diff v1.0.0..v1.1.0
```

### Output

```
🚩 Flag changes (main → HEAD):
  + payment-v2 (enabled: true, rollout: 10%)
  ~ new-checkout:
      rollout: 10% → 50%
  - legacy-nav (removed)
```
